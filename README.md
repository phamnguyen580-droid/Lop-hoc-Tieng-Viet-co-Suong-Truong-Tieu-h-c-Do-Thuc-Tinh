# Lớp học Tiếng Việt của cô Sương – Lớp 2

Trang web một tệp (`index.html`), không cần máy chủ hay khoá API.

## Đưa lên GitHub Pages
1. Tạo kho (repository) mới trên GitHub.
2. Tải lên toàn bộ tệp trong thư mục này (`index.html`, `.nojekyll`, `README.md`).
3. Vào **Settings → Pages**, chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)`, bấm **Save**.
4. Sau 1–2 phút, trang có tại `https://<tên-tài-khoản>.github.io/<tên-kho>/`.
